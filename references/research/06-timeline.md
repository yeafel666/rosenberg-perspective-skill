# 06 - 人物时间线：Marshall B. Rosenberg (1934–2015)

> **纠正**: Rosenberg去世于2015年2月7日，而非2005年。

## 完整时间线

| 时间 | 事件 | 对思维的影响 |
|------|------|------------|
| **1934年10月6日** | 出生于俄亥俄州Canton，犹太家庭 | 成长中经历的反犹主义成为他对暴力语言敏感性的来源 |
| **~1940s** | 在底特律长大 | 底特律的种族紧张环境（后来的种族暴乱）成为他社会行动的起点 |
| **童年** | 被叫"kike"（反犹侮辱词） | 直接体验了标签和去人性化的痛苦——这成为NVC反对"敌人形象"的个人根源 |
| **~1950s** | 本科就读于University of Michigan | 接触人本主义心理学思想 |
| **1961年** | 在University of Wisconsin-Madison获得临床心理学博士学位，师从Carl Rogers | Rogers的无条件积极关注、共情、一致性成为NVC的理论基石 |
| **1960s早期** | 开始发展NVC的概念框架 | 从传统临床诊断体系转向关注人类需要 |
| **1960s** | 在底特律种族冲突中开始调解工作 | 底特律"在火光中燃烧"——决心找到阻止暴力的沟通方式。这是NVC的实践起点 |
| **~1960s-70s** | 在学校、监狱、社区中实践NVC | 将理论从诊所扩展到更广泛的社会场景 |
| **1972年** | 出版《Mutual Education》 | 早期教育思想的系统表达 |
| **1983年** | 出版《A Model for Nonviolent Communication》 | NVC四步模型的首次系统性出版 |
| **1984年** | 创立Center for Nonviolent Communication (CNVC) | 从个人教学转变为组织化全球运动 |
| **1986年** | 出版《The Miracle of Dialogue》(与Armand DiMele合著的对话) | — |
| **1986年** | 出版《Raising Children Compassionately》 | 将NVC应用于育儿 |
| **1989年** | 出版《The Surprising Purpose of Anger》 | 深入探讨愤怒作为"未被满足的需要的信号" |
| **1990s** | 开始大规模国际和平调解工作 | 进入卢旺达（大屠杀后）、尼日利亚（部落冲突）、巴勒斯坦/以色列、塞尔维亚/克罗地亚、北爱尔兰等冲突地区 |
| **1994年** | 在巴勒斯坦遇到Amal Hadweh | 培养了第一位巴勒斯坦NVC培训师，此后NVC在中东持续发展 |
| **1999年** | 出版《Nonviolent Communication: A Language of Life》(核心著作) | NVC的最终版系统表达，成为全球畅销书，被翻译成30+语言 |
| **1999年** | 出版《We Can Work It Out》 | 将NVC应用于冲突解决 |
| **2000s** | 出版《Getting Past the Pain Between Us》(2000)、《The Heart of Social Change》(2004)、《Speaking Peace》(2005) | 持续扩展NVC到新领域 |
| **2003年** | 出版《Life-Enriching Education》 | 将NVC应用于教育系统 |
| **2003年** | 出版《Practical Spirituality》 | 探讨NVC与灵性的关系——注意这里他使用了"灵性"一词 |
| **2004年5月** | Inquiring Mind采访 "The Traveling Peacemaker" | 最重要的深度访谈之一，展示了他对文明结构（8000年支配文化）的深层思考 |
| **2005年** | 出版《Being Me, Loving You》(relationship NVC)、**《Speak Peace in a World of Conflict》** | 后者是NVC在冲突场景中的最终系统表达 |
| **2005年** | 出版《Teaching Children Compassionately》(Montessori教育主题演讲) | 展示了他对教育改革的激进观点 |
| **2000s-2010s** | 持续全球旅行教学，每年访问约35个国家 | NVC传播至60+国家，培养了数千名认证培训师 |
| **2015年2月7日** | 去世，享年80岁 | — |

## 身后影响（2015年后）

| 时间 | 事件 |
|------|------|
| 2015年后 | CNVC继续运营，NVC全球社区持续扩大 |
| 2015年后 | NVC被整合进多种领域：教育、医疗、企业培训、监狱改造、国际发展 |
| 2015年后 | NVC与正念运动、社会正义运动、环境运动的交叉 |
| 2020s | NVC在社交媒体和在线学习平台的二次传播 |
| 持续 | 每年举办International Intensive Trainings (IITs) |

## 思想转折点

### 转折1: 从临床到社会（1960s）
- 从临床心理学家 → 社会调解者
- 标志：离开诊所，进入底特律社区

### 转折2: 从诊断到需要（1960s）
- 从"诊断什么病" → "什么需要没有被满足"
- 这是最根本的认识论转变

### 转折3: 从美国到全球（1990s）
- 从美国本土教学 → 全球和平调解
- 标志：卢旺达、尼日利亚、巴勒斯坦的工作

### 转折4: 从技巧到文明批判（2004年采访中体现）
- 从NVC作为沟通技巧 → 对8000年支配文化的批判
- 这在他的晚期访谈中最为明显——他不只是在教沟通，而是在提出一种文明诊断
